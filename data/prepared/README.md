# Prepared datasets

Derived train/validation corpora live here, one directory per version. They are
generated by `mikuru-lm prepare-dataset` and are never edited by hand.

Each version directory must contain:

| File | Contents |
| --- | --- |
| `train.jsonl` | Records with `"split":"train"` |
| `validation.jsonl` | Records with `"split":"validation"` |
| `manifest.json` | Split source, seed, counts, and per-source license summary |
| `README.md` | Approval status, provenance, and known gaps for that version |

## Rules

- **Approved sources only.** A source is not approved just because it is
  documented; see `data/research/ATTRIBUTION_AND_LICENSES.md`.
- **Preparation never overwrites.** To regenerate a version, deliberately
  remove the directory first.
- **No hand edits.** Record text, license, and provenance fields must continue
  to match the source. Only the `split` field is assigned by preparation.
- **Validation stays out of tokenizer training.** Train the BPE tokenizer on
  `train.jsonl`, or pass a combined file — the tokenizer CLI filters records
  labelled `validation`.

## Current versions

third-party license copies in [`data/third-party/`](../third-party/).
Preparation never edits imported text; it only assigns split labels.
