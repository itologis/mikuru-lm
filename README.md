# Mikuru

My journey toward building Mikuru, my own AI companion, from the ground up.

## Goals

- Learn how neural networks and weights work.
- Implement forward propagation and backpropagation.
- Train small neural networks from random initialization.
- Explore tokenization and language modeling.
- Gradually develop a text-based AI companion.
